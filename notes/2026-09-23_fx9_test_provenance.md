# FX9 test provenance isolation (NOT EXPERIMENTAL EVIDENCE)

A pre-existing test, test_run_m9_audit.py::test_generate_and_score_end_to_end_on_synthetic_data, monkeypatches the script's REPO_ROOT to pytest's temporary directory but did not redirect provenance.RESULTS_DIR. During the allowed short login-node pytest run, provenance.finalize appended synthetic test records to the real results/RUN_LOG.jsonl and wrote their configuration YAMLs under results/configs. Its CSVs and shadow stores were all temporary; no experimental result CSV, figure, or table was overwritten. This violates the explicit FX9 no-production-output-write rule even though the test itself was short. The entries are retained as history. Fixed with a tests/conftest.py autouse fixture isolating provenance to tmp_path, and a guard in production finalize that requires PBS_JOBID for the actual results root. All subsequent test runs use the isolated log.
