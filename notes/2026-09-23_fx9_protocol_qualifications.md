# FX9 qualifications carried into final reporting

The CUB gate still fails after the prescribed train-validation grid. Logs from PBS 184357[1] show last-task accuracy 0.128690063 / 0.171307992 / 0.281962718 for M1/M2/M5 and BWT +0.360410384 / +0.481171795 / +0.313723256. Balanced cross-entropy is implemented and tested, but its code correction does not eliminate the late-learning confound under one round per task. The plan explicitly directs keeping the selected configuration and continuing. No extra tuning outside the grid is authorized by this result.

The M1 objective in §6 explicitly preserves KD_mean(current ∪ buffer). Duplicating only one group changes that KD mean in general. The requested group-duplication invariance is therefore tested on the balanced CE component (KD disabled), and the unchanged union-KD implementation is separately checked. Full M1 gradient invariance with nonzero KD would contradict the specified objective; it is not claimed.

The FX1 accountant counts release intersections for each unit and assumes the supplied noise multiplier is normalized to that unit's sensitivity. The requested M9 ledgers are calibrated to U1. Feeding their U1 multiplier into U2–U4 record composition produces the requested FX1 convention values, but does not establish cross-unit group sensitivity. CSV scope fields and the briefing explicitly qualify those values. Neither the M9 mechanism nor the FX1 accountant is changed in FX9.

The requested empirical epsilon calculation maximizes pointwise one-sided Clopper–Pearson lower bounds across thresholds, in both directions. That maximum is not a simultaneously calibrated confidence bound, and the underlying target/shadow pairs are dependent. It is reported as the requested empirical audit statistic, never a formal DP certificate.

An additional reporting bug was found in the old leakage half-life bootstrap: censored replicates at E=6 were counted as finite observations, giving [6,6] intervals for flat curves. New FX9 producers track censoring correctly; preserved M0/M3/M8 per-combo results are not rewritten. The paper transcription omits historical endpoints when the point estimate is censored, and TAB04 already displays these as >E with no finite CI.
